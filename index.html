Algorand wallet for Chrome and Firefox

Know what you sign.

SignA (say "signer") is an Algorand wallet that spells out every transaction before you approve it. Your keys stay encrypted in your browser, and a dApp only ever sees the accounts you choose to share.

Install dApp guide

Pre-release. SignA is not in the Chrome Web Store or on AMO yet. Builds come from txn.group as a zip file.

A look inside

SignA follows your system's light or dark setting, or you can pick one in Preferences.

What SignA does

Side panel

The toolbar icon opens the wallet in Chrome's side panel or Firefox's sidebar, so it stays open while you use a dApp. Signing prompts open in their own window.

Modern dApp support

SignA exposes an ARC-0027 web provider beside window.algorand and window.AlgoSigner. use-wallet v5 connects without a shim.

Connections you can see

The wallet lists every dApp connection per network, with the addresses it can see and a button to revoke it.

One account, many networks

An Algorand keypair is the same on every chain. SignA stores each account once and you pick the networks it shows on.

Indexer optional

A network can point at a bare algod node. Features that need an indexer say so rather than failing.

Ledger accounts

Ledger addresses sit beside vault accounts. The device holds the key and the wallet only sees the signature.

For dApp developers

SignA injects three routes into every page. All three share one signing implementation, so pick the one your tooling expects.

  • ARC-0027 provider, found by use-wallet v5 and other libraries built on @agoralabs-sh/avm-web-provider.
  • window.algorand, the ARC-0001 style object with enable and signTxns.
  • window.AlgoSigner, kept for dApps written against AlgoSigner before 1.10.0. 
// Ask for accounts on TestNet
const { accounts } = await window.algorand.enable({
  genesisID: 'testnet-v1.0',
});

// Sign a transaction the dApp built
const [signed] = await window.algorand.signTxns([
  { txn: base64Txn },
]);

Built-in networks

MainNet, TestNet and BetaNet use Nodely's free tier and cannot be edited. Add any other network, such as a local AlgoKit node, from Settings. See Adding a network.

Where it comes from

SignA began as a fork of AlgoSigner, which PureStake archived at v1.11.0 under the MIT license. txn.group moved it to Manifest V3, rebuilt the interface in Svelte 5, and updated it to algosdk 3.x. The signing path is checked against byte-exact golden vectors in CI.
